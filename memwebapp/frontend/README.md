# OWNnote Dashboard

A modern, customizable dashboard platform for visualizing customer conversations and analytics using AI.

---

## 🚀 Features

- **Custom Dashboards:** Create, edit, and manage multiple dashboards.
- **AI-Powered Insights:** Generate charts and word clouds from conversation data.
- **Interactive Visualizations:** Bar, Pie, Line, Area, Scatter, and Word Cloud charts.
- **Bookmarking:** Save and filter your favorite charts.
- **Responsive UI:** Built with React, Tailwind CSS, and shadcn-ui.
- **Popup & Fullscreen Views:** Expand charts for detailed analysis.
- **Data Filtering:** Search and filter charts by query or bookmark status.
- **Testing:** Includes unit and integration tests for components and utilities.

---

## 🛠️ Tech Stack

- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn-ui](https://ui.shadcn.com/)
- [Recharts](https://recharts.org/) (charts)
- [d3-scale](https://github.com/d3/d3-scale) (color scales)
- [Supabase](https://supabase.com/) (backend, if enabled)
- [Jest](https://jestjs.io/) & [React Testing Library](https://testing-library.com/) (testing)

## 📦 Getting Started

### 1. **Clone the repository**

```sh
git clone <YOUR_GIT_URL>
cd memwebapp/frontend
```

### 2. **Install dependencies**

```sh
npm install
```

### 3. **Run the development server**

```sh
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🧪 Testing

### **Run all tests**

```sh
npm test
```

### **Run tests in watch mode**

```sh
npm run test:watch
```

- Tests are located in `src/__tests__/` and alongside components as `*.test.tsx`.
- Uses Jest and React Testing Library for unit and integration tests.
